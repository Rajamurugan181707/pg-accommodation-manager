PG Accommodation Management System

A Java app for the owner or warden of a PG hostel. It tracks rooms and beds, registers tenants, bills rent and mess every month, records payments, and shows who still has to pay. Everything is stored live in MySQL.

Download the app (.jar) View the code on GitHub
Java 8+JDBCMySQLSwing GUI + consoleDS: Array

Four modules

Each module is its own screen in the app. All of them read and write the same MySQL database.

Room

  • Rooms as cards, with each bed shown as taken or free
  • Find a room by number (binary search)
  • Sort by rent; show only rooms with free beds
  • Add, change rent, delete

Tenant

  • Register a tenant and give them a bed
  • Search by name as you type (linear search)
  • Shift room, change mess plan
  • Check out, with the deposit and dues shown first

Rent

  • Monthly bill = bed rent + mess charge
  • Part payments, with overpaying blocked
  • Dues list, with the most pending first
  • Bill, full statement and receipts

Mess

  • Meal plans with headcount and income
  • Add plans; move tenants between them
  • Weekly menu, with today marked
  • Mess charge added to the monthly bill

Screens

A dark, colour-blind-safe interface. All text is white, and every state is written in words and shown with its own shape, never by colour alone.

Transactions

Register, shift and checkout change two tables at once, so they run inside one transaction.

Frozen bills

Each month's bill is saved once. A later rent change or room shift never rewrites old, paid bills.

Safe SQL

Every query uses PreparedStatement, so typed text never becomes SQL.

Input checks

Amounts, dates, phone numbers, emails and lengths are checked before anything reaches MySQL.

Run it on your computer

The app runs on your own machine against your own MySQL, so all data is live and stays with you.

1

Install Java and MySQL

Java 8 or newer, and MySQL 5.7 or newer.
2

Download

Get PG-Manager.jar and pg-accommodation-source.zip from the latest release, and unzip the ZIP.
3

Create the database

This makes the tables and loads sample data. Run it from the unzipped folder.
mysql -u root -p < sql/schema.sql
Then put db.properties next to the JAR and set your MySQL user and password in it.
4

Start the app

java -jar PG-Manager.jar
For the console version instead:
java -cp PG-Manager.jar com.pgms.ui.Main
